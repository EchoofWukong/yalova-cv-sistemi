# 🎓 Yalova CV Sistemi

Laravel kullanılarak geliştirilmiş, kullanıcıların bilgilerini girip istedikleri temayı seçerek saniyeler içinde otomatik olarak profesyonel özgeçmiş (CV) oluşturabilecekleri web tabanlı bir platformdur.

## 🌟 Özellikler

- **Kullanıcı Paneli:** Güvenli kayıt ve giriş sistemi (Authentication).
- **Dinamik Veri Girişi:** Kişisel bilgiler, eğitim geçmişi, iş tecrübeleri ve yeteneklerin kolayca sisteme kaydedilmesi.
- **Tema Seçimi:** Kullanıcıların zevkine veya başvurdukları sektöre uygun farklı görsel şablonlar (temalar) arasından seçim yapabilmesi.
- **Otomatik CV Üretimi:** Girilen verilerin anında seçilen temaya entegre edilerek hazır bir CV formatına dönüştürülmesi.

## 🛠️ Kullanılan Teknolojiler

- **Backend:** Laravel (PHP)
- **Frontend:** Laravel Blade, HTML/CSS, JavaScript
- **Veritabanı:** MySQL / PostgreSQL
- **Yayınlama (Deployment):** Render
